# 海外EBP・犯罪予防リソース日本語ナビ

## 構造
- 課題検索：赤（実例）→青（関連対策）
- 対策検索：青（海外情報源）→赤（実例）
- 第1階層：選ぶ
- 第2階層：日本語で理解する
- 第3階層：一次資料を読む

検索・関係データは `data/` のJSON、長文解説・実例解説・翻訳は `content/` のMarkdownで管理します。

統計折りたたみは研究HUBと同じマーカーを使用します。

```html
<!-- STATS_DETAIL_START -->
## 統計で確認する
...
<!-- STATS_DETAIL_END -->
```
