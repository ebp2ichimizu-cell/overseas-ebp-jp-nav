# POP Center｜Burglary of Single-Family Houses

### 最初に結論

POP CenterのGuideは、
「住宅侵入窃盗」という大きなcrime categoryを、
自地域で使える問題へ分解するための資料です。

Guide自身が強調しているのは、

平均的なburglary像をそのまま自地域へ当てはめない

ということです。

小さな地域の中でもburglary patternは違います。

そこで、

- どの住宅が狙われるか
- どこから入るか
- いつ起きるか
- 何が盗まれるか
- 誰が管理できるか

を分析し、
Responseを選びます。

## 1．このGuideの対象

主にsingle-family houses。

owner-occupied / detached homesを中心に扱います。

apartments等と共通する点もありますが、
access pointやproperty managementが違うため、
crime prevention techniqueも変わります。

### 日本で読むとき

日本の戸建住宅と
米国のsingle-family housesを
同一視しない。

住宅構造、
塀、
庭、
道路、
土地利用、
駐車空間

等の違いを確認して使います。

## 2．平均像を作りすぎない

POP Centerは、
burglaryが多いcrimeであるため、
大きなdatasetの平均値だけを見ると、

「典型的burglary」

という誤ったイメージを作る可能性を指摘しています。

実務では、

- specific neighbourhood
- street
- housing type
- time
- entry point

に分けてtrendを探します。

## 3．Targetを見る

分析項目例：

- 住宅タイプ
- corner lotか
- 道路からのvisibility
- vegetation / fence
- 入口の数
- door / window security
- alarm
- occupancy pattern
- wealth cues
- 車両の有無

### 実務の観点

「防犯意識が低い住宅」

と人の態度だけに帰属させず、
住宅そのもののopportunity structureを見る。

## 4．Placeを見る

Guideでは、

- accessibility
- visibility
- seclusion
- street design
- proximity to offenders
- neighbourhood homogeneity

等を扱います。

例えば、
dense shrubberyやprivacy fenceは、
住民にはprivacyを提供する一方、
offenderにもconcealmentを提供する場合があります。

### サイトによる独自解説

CPTEDでは、

「見通しを良くすればよい」

という単純化ではなく、

resident privacy
と
offender concealment

の両方を見る必要があります。

## 5．Offender knowledgeを見る

一度侵入した住宅について、
offenderは、

- entry point
- layout
- security
- occupancy

を知ることがあります。

その知識がrepeat burglaryへつながる可能性があります。

これは、
repeat victimisation / cocooningと接続します。

## 6．Local analysis questions

自地域で確認する：

- どの住宅が狙われているか
- repeat victimはいるか
- near-repeatはあるか
- どこから侵入しているか
- 侵入方法は何か
- 犯行時間はいつか
- 盗品は何か
- 逃走方法は何か
- offenderはlocalか
- stolen goodsはどこへ流れるか
- 住宅管理者は誰か

## 7．Responseを一つに固定しない

POP Centerは、
Responseをlocal circumstancesへ合わせることを強調しています。

Response例：

- burglar alarms
- locks / doors / windows
- target hardening
- Neighbourhood Watch
- property marking
- CPTED
- offender targeting
- stolen goods market interventions

Summary tableでは、
それぞれについて、

How it works
Works best if
Considerations

を整理しています。

## 8．Law enforcementだけで終わらない

POP Center summaryは、
law enforcement responsesだけでは、
problem reductionに十分でない場合が多いと説明しています。

これは、
enforcementが不要という意味ではありません。

offender targeting
＋
place management
＋
target hardening

等を組み合わせます。

## 9．古いGuideをどう使うか

Guide No.18は2002年に作成された古い資料です。

したがって、
現在の技術・crime patternをそのまま反映しているわけではありません。

一方、

「local problemを分解してResponseを選ぶ」

というproblem-solving structureは現在も利用できます。

### サイトによる独自解説

具体的なsecurity technologyについては
新しいsourceで更新し、

analysis frameworkとしてGuideを使うのが適切です。

## 10．実務で持ち帰ること

1．「住宅侵入窃盗」という一分類のままResponseを決めない。

2．Target・Place・Offenderへ分解する。

3．自地域のhousing typeを見る。

4．repeat / near-repeatを分析する。

5．law enforcementとsituational preventionを組み合わせる。

6．古いGuideの技術情報は現在資料で補完する。
