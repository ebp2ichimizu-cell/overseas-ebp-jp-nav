# Center for Problem-Oriented Policing（POP Center）｜日本語ナビ
再構築用コンテンツ原稿

> POP Centerは、特定の犯罪・秩序問題を「問題から」調べ、分析し、対応策を検討するための代表的なProblem-Oriented Policingリソースです。

## このリソースで何ができるか

POP Centerでは、
「この犯罪には何が効くか」だけでなく、
「この問題はどのように起きるのか」
「何を分析すべきか」
「どのような対応策が考えられるか」
を問題別に確認できます。

特に、現場で具体的な問題がすでに見えている場合に有用です。

## 主な資料群

### Problem-Specific Guides
特定の犯罪・秩序問題ごとに、
- 問題の特徴
- 発生要因
- 分析項目
- 対応策
- 効果が限定的な対応
- 評価
などを整理したガイド。

### Problem-Solving Tool Guides
問題解決の分析・設計・評価で使う考え方や手法を扱うガイド。

### Response Guides
特定の対応方法や戦略について整理した資料。

## どこを読めばよいか

### 問題の概要｜The Problem / Overview
問題の定義・特徴を把握。

### 発生の特徴｜Patterns / General Description
時間、場所、対象、反復性などの特徴を確認。

### 原因・寄与要因｜Factors Contributing to the Problem
問題が継続する条件を確認。

### 分析で確認する事項｜Understanding the Problem / Asking the Right Questions
現場で追加確認すべき情報を整理。

### 対応策｜Responses
考えられる対応方法を確認。

### 効果が限定的な対応｜Responses With Limited Effectiveness
過去に十分な効果が確認されていない対応を確認。

### 効果測定｜Measuring Effectiveness
評価指標・比較方法を確認。

## 実務での使い方

1. 自地域の問題を具体化する
2. 最も近いProblem-Specific Guideを探す
3. 問題の定義・特徴を確認する
4. 自地域で不足している分析項目を洗い出す
5. 対応策を候補として見る
6. Crime Reduction Toolkitやレビュー研究で、効果エビデンスを別途確認する
7. 評価方法を実施前に考える

## 理論との関係

POP Centerのガイドは、Routine Activity Theory、Situational Crime Prevention、Problem Analysis Triangleなどの理論・概念と関係する場合があります。

ただし本サイトでは、
**資料で明示されている関係**
と
**サイト側が推測した関係**
を混同しません。

理論との関係を示す場合は、原資料または確立した研究系列で確認できる場合に限ります。

## 注意点

- ガイドの公開時期が古い場合がある
- 法制度・技術・犯罪手口が変わっている可能性がある
- 記載されたResponseが現在も有効とは限らない
- 米国中心の制度・環境を前提とする資料が多い
- ガイド掲載＝日本でそのまま採用すべき、ではない
